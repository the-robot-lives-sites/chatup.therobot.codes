Privacy policy

Chat to Markdown works entirely on your machine. Last updated 2026-09-15.

No data collection

The extension reads the conversation visible in the page you are on, converts it to Markdown or YAML locally, and hands the result to you (preview, clipboard, or download). Nothing is transmitted to any server — ours or anyone else’s.

No retention

The Robot Lives retains no user data and no personal information. The extension has no backend: exports exist only in your browser until you copy or save them yourself, and nothing about you or your conversations ever reaches us — there is nothing to store, sell, or share.

No accounts, analytics, or tracking

There are no accounts, no analytics, no tracking, and no remotely hosted code. All logic ships inside the extension bundle.

Permissions

  • The content script loads on all http(s) pages so it can recognize supported chat UIs wherever you use them — including self-hosted Open WebUI instances, which are detected by their DOM structure rather than by hostname. On pages it does not recognize, the script does nothing: no UI, no reads, no writes.
  • On a recognized chat site it reads the conversation you are viewing — the site you must already be logged into — so it can convert it for you.
  • clipboardWrite copies the generated Markdown or YAML to your clipboard when you press Copy.

This website

chatup.therobot.codes is a static landing page. It does not set cookies, does not run analytics, and does not collect form data. Our hosting provider may process brief, standard request logs for security and abuse prevention; these are not used to identify visitors and are not retained by The Robot Lives as user data.
